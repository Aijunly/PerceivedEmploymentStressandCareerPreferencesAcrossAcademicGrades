# Replication Code Package

This package reproduces the quantitative results reported in the manuscript
"A Survey-Based Analysis of Perceived Employment Pressure and Career Preferences
Among Young Adults"
(RQ1 descriptive profile, RQ2 grade differences, RQ3 stress-choice associations),
starting from the analysis-ready data files described below.

## Contents

- `step20_prepare.py` ... `step29_fig_methods.py`: analysis scripts, numbered in execution order
- `poly_utils.py`: shared module (polychoric correlation, nearest positive-definite projection); imported by `step22_efa.py` — keep both files in the same directory
- `data_dictionary.csv`: English labels and value codes for every column of the five data files
- Data files (de-identified):
  - `论文二数据集_1026.xlsx` — main sample (N = 1,026; paper-based 779 + online 247)
  - `网络问卷2_清洗数据.xlsx` — second batch (N = 553, online channel)
  - `合并问卷清洗数据_1579.xlsx` — pooled sample (N = 1,579)
  - `建模数据集.xlsx` — modelling dataset used by RQ2/RQ3
  - `论文二数据集_1579.xlsx` — pooled dataset with derived variables

The two `论文二数据集_*.xlsx` files **already contain the factor scores** `F1` / `F2`
(unit-weighted, the scores used throughout the manuscript) and `RF1` / `RF2`
(regression-based, appendix control only). They are written back by `step22_efa.py`.

## Environment

- Python 3.11+ (tested with Python 3.11, pandas 2.x, statsmodels 0.15.0, factor_analyzer 0.5.1)
- `pip install -r requirements.txt`
- Console output is forced to UTF-8 at the top of every script, so the pipeline runs
  unchanged on Windows code pages as well as on Linux/macOS.

## How to run

All paths are relative to this directory; each script reads and writes files here.
The five data files listed under *Contents* must be placed in this directory before
running. Survey response files are distributed under the Academic Research Use
Terms in `../LICENSE.md`, not under the MIT licence (see *License and data
availability*).

1. `python step22_efa.py` — EFA; writes the factor scores `F1`/`F2`/`RF1`/`RF2` back into the two `论文二数据集_*.xlsx` files
2. In any order: `step21_descriptives.py`, `step23_grade_trend.py`, `step26_pooling_test.py`
3. `python step24_stress_choice.py` then `python step25_intent_mediation_moderation.py`
4. `python step27_finalize.py`
5. RQ1 pooled-sample sensitivity: `step28_rq1_pooled.py` then `step28b_plots_rq1.py`
6. Method figure: `step29_fig_methods.py` (independent)

`step20_prepare.py` rebuilds the two `论文二数据集_*.xlsx` files from
`合并问卷清洗数据_1579.xlsx`. It is **not needed for replication** (the two
datasets are distributed ready to use) and it **drops** `F1`/`F2`/`RF1`/`RF2`,
so if you do re-run it, run `step22_efa.py` again immediately afterwards:

```bash
python step20_prepare.py   # optional: rebuilds the datasets; deletes the factor-score columns
python step22_efa.py       # required afterwards: restores F1/F2/RF1/RF2
```

Each script prints its key statistics to the console and writes **numerical result
tables** (`论文二_输出/*.xlsx`) and **figures** (`figs2/*.png`) into subdirectories it
creates on demand. No narrative reports are produced: the manuscript text is not
generated by the code, so the outputs to compare against the paper are the Excel
sheets and the figures.

## Reproducibility notes

- Respondent `id` is renumbered 1..N in every data file: unique within each file, and the
  same respondent carries the same `id` in `论文二数据集_1026.xlsx` and
  `论文二数据集_1579.xlsx` (the 1026 sample is the first 1026 rows of the pooled file).
- Figures are written at 600 dpi (720 dpi for the five RQ1 pooled panels), 174 mm wide,
  without in-figure titles.
- `SEED = 42` wherever resampling or permutation is used.
- Re-running the pipeline on the distributed data files reproduces the reported
  estimates exactly (checked as zero difference on all 96 shared columns of the two
  datasets, and on every value written to the Excel result tables).
- Output files: `论文二_输出/*.xlsx` (one workbook per analysis step) and `figs2/*.png`
  (20 figures, including the six supplementary panels).

## Coding conventions referenced in the manuscript

- Public-sector preference is the single item Q10_1 by design (Q10_2 measures foreign-funded firms and is NOT merged into it).
- Q11 items coded 0/1/2 with 99 = "not sure"; 99 is treated as missing in the main index (index A) and scored as 1 in the sensitivity index (B).
- Continuous predictors are standardised by the SD of the dataset in which each model is estimated; `batch` is retained in all pooled models, and `mode` (online vs paper) is retained in every model.
- Career intention (4 categories) is reconstructed for the second batch following the rule in `step20_prepare.py`.
